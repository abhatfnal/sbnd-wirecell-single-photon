# Technical index of the NC-Delta first-look analysis (Phases 1-19)

Date: 2026-11-11. The map of the whole analysis: for each phase the branch (all pushed to `origin` except Phase 19), the commit, the question answered, the authoritative document, tables (`tables/<dir>/`), plots (`plots/<dir>/`), status and the caveat to carry. Large row-level products live outside Git in `$SP_DATA/<dir>/official_ncdelta/` with a `metadata.json`. The baseline numbers are collected in `NCDELTA_FROZEN_WIRECELL_BASELINE.md`.

**Numbering note.** Phases 6-19 carry their number in the roadmap and the documents. Phases 1-5 predate that convention and their numbers are inferred from document cross-references ("Phase 3's 117 natural", "the Phase-4 tables" for the background mechanisms, "Phase 2 status" in the design document); Phase 2 has no branch of its own (its commits sit on the Phase-1 branch history), and Phase 5 spans two branches (signal arrival readiness, official signal baseline).
